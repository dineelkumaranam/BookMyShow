# MovieBook - BookMyShow-like Demo

A front-end movie booking demo built with HTML, CSS and vanilla JavaScript.

## Features
- Movie cards and search
- Theatre selection
- Showtime selection
- Interactive seat selection
- Demo payment/confirmation
- Booking ID generation
- `window.close()` after successful booking when opened as a JavaScript popup
- Responsive mobile layout

## Run
Open `index.html` in a browser.

For the close-window behavior, open the booking page/window using JavaScript `window.open()`. Modern browsers do not allow a normal user-opened tab to close itself.

This is a front-end demo. It does not process real payments or store bookings on a server.
